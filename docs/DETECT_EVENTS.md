# 9단계 탐지 연습 사건 계약

`npm run detect:test`는 학생이 작성한 `src/detect.mjs`의 `detect(events)`에 가상 조회 사건을 전달합니다. 기존 사건의 기본 형식은 다음과 같습니다.

```js
{ at: '2026-10-01T00:00:00.000Z', method: 'GET', identity: { sub: 'learner_fixture' } }
```

## 원본 계약 호환

배열 전체에 `deviceId`와 `signals`가 없으면 원본 사건 계약을 적용합니다. 같은 `identity.sub`의 GET이 어느 10분 구간에서든 **120건을 넘을 때만** 다음 세 항목을 반환합니다.

```js
{ action: 'propose_revocation', reasonCode: 'burst_read', subject: 'learner_fixture' }
```

정확히 120건, 정상 조회량, 사용자별로 나뉜 사건, 10분 밖으로 흩어진 사건에는 `{ action: 'observe' }`를 반환합니다. 이 기준은 시작 틀의 원본 문서·시험과 같습니다. 원본 사건에 없는 기기·네트워크·지역 정보를 생성하지 않습니다. 원본 입력만으로 네트워크 이상이나 특정 기기를 확인했다고 주장하지 않습니다. `subject`를 실제 회수 대상 기기로 해석하는 운영 경로는 별도 확인이 필요하며, 코드가 사용자 전체의 권한을 변경하지 않습니다.

확장 사건이 하나라도 있으면 아래 복합 조건을 적용합니다. 일부 확장값이 누락된 사건을 원본 기준으로 우회시키지 않고 원본·확장 사건의 조회량도 합산하지 않습니다.

## 복합 의심 사건용 로컬 연습 확장

네트워크와 다량 조회가 함께인 규칙을 연습하려고 사건에 선택적으로 다음 신호를 제공합니다. 이 확장은 운영 엔진에 이미 연결된 사건 형식이라는 뜻이 아닙니다.

```js
{
  at: '2026-10-01T00:00:00.000Z',
  method: 'GET',
  identity: { sub: 'learner_fixture' },
  deviceId: 'aaaaaaaaaaaaaaaa',
  signals: { source: 'judge_fixture', network: 'unusual' }
}
```

같은 `identity.sub`·`deviceId`의 GET 중 `signals.source`가 `judge_fixture`이고 `signals.network`가 `unusual`인 사건만 셉니다. 어느 10분 구간에서든 **120건을 넘을 때만** 아래의 별도 탐지 결과를 반환합니다. 정확히 120건과 정확히 10분 경계를 시험합니다. 순서가 뒤섞여 있어도 사건 시각으로 비교합니다.

시각은 `Z`로 끝나는 ISO UTC이며 초 단위(`2026-10-01T00:00:00Z`)와 소수 초 1~3자리 표기를 모두 받습니다. 밀리초 생략만으로 사건을 버리지 않으며 존재하지 않는 날짜와 시간대가 없는 문자열은 탐지 근거로 사용하지 않습니다.

```js
{
  action: 'propose_revocation',
  reasonCode: 'burst_read',
  subject: 'learner_fixture',
  deviceId: 'aaaaaaaaaaaaaaaa'
}
```

확장 사건의 대상은 전달된 사건의 가명 사용자와 확인된 가상 기기 ID 한 개로 한정합니다. 기기 ID는 16자리 소문자 16진수여야 하며, 확장 사건에서 누락되면 회수 제안을 만들지 않습니다. 가상 입력 생성기가 지정한 기기를 연습용 대상으로 사용하며, ID 형식이나 `judge_fixture` 문자열만으로 운영 기기 확인을 증명하지 않습니다. 운영 호출자는 검증된 사건만 전달해야 합니다.

한 번의 호출에 복합 조건을 충족하는 기기가 여러 개여도 대상 한 개만 제안합니다. 정상 기기·사용자 전체·기기 목록을 회수 대상으로 확장하지 않습니다. 이는 의심에 따른 회수 제안이며 직접 회수하지 않습니다. 회수 API와 권한 변경은 없고 실제 회수와 경과 시간 측정은 심판이 별도로 확인합니다. `src/decider.mjs`의 접속 허용·거부·추가 확인 응답 다섯 항목은 변경하지 않습니다.

확장 사건에서 그 밖에는 `{ action: 'observe' }`입니다. 네트워크 이상만 있거나 정상 네트워크의 다량 조회이면 제안하지 않습니다. 지역은 읽거나 판단하지 않습니다. 신호 누락·다른 출처·알 수 없는 네트워크와 누락·잘못된 UTC 시각은 탐지 근거로 세지 않습니다. 기기 정보가 없는 확장 사건도 `observe`로 유지하며 기기값을 생성하지 않습니다. 사용자·기기별 사건을 합산하지 않고 10분 밖 사건도 같은 구간으로 세지 않습니다.

입력 정리 함수는 제공된 가명 사용자·기기·메서드·선택적 판정(`allow`, `deny`, `step_up`)만 복사합니다. 탐지 함수는 위 복합 규칙에 필요한 시각과 가상 네트워크 신호를 추가로 읽습니다. 메모·토큰·실명·지역·전체 사건을 복사하거나 저장·출력하지 않습니다. 사건 판정값만으로 의심을 확정하지 않습니다.

이 파일의 사건 모양은 **로컬 연습용**입니다. 브라우저가 보낸 사용자 번호를 신원으로 취급하지 않습니다. 운영 반 엔진이 검증한 사건을 전달하고 회수 제안을 집행하는 경로는 별도로 연결·시험해야 합니다. 이 명령의 통과를 실제 접속 차단이나 심판 판정으로 표시하지 않습니다.
