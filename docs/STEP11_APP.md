# 11단계 접속 앱 화면

앱 이름은 **최 부장 비밀 자료실**입니다. 기존 자료실의 첫 화면에 manifest와 PNG 아이콘,
브라우저 설치 안내, 연결 상태 및 기기 승인 상태 표시를 추가했습니다. 별도 접속 프로그램은 만들거나 설치하지 않습니다.

현재 서버에는 브라우저용 기기 승인 상태 조회 계약이 없습니다. 화면은 **기기 승인: 확인 불가**를 표시합니다.
로그인·메모 조회 성공·앱 설치·앱 창 실행을 기기 승인으로 간주하지 않습니다.
실제 승인 상태 조회·승인 요청은 운영 엔진이 확인된 상태를 제공하는 별도 계약 없이는 연결하지 않습니다.
기기 키·토큰을 localStorage·sessionStorage·IndexedDB·서비스 워커 캐시에 저장하지 않습니다.
기존 메모 API·판정기·탐지기·서버 인증과 HttpOnly 갱신 쿠키 처리는 보존합니다.

서비스 워커는 공개 `/offline.html` 안내만 캐시합니다. 메모·인증 API·첫 화면을 캐시하지 않습니다.
API는 탐색 요청이어도 가로채지 않으며, 서버의 401·403 등 거부 응답을 오프라인 성공 응답으로 바꾸지 않습니다.
첫 화면 탐색의 네트워크 실패에만 안내를 제공합니다. 처음 방문부터 오프라인이거나
서비스 워커를 지원하지 않는 브라우저에서는 오프라인 안내가 준비되지 않을 수 있습니다.

## 실행과 확인

터미널에서 `npm.cmd run build -- --local`을 실행합니다. 이 명령은 배포하지 않습니다.
배포 반영은 이 변경이 포함된 버전을 공식 Vercel 배포 절차로 올린 뒤 확인해야 합니다.
이번 작업은 저장점 요청이 아니므로 기존 10단계 저장점 기록과 설정 단계는 유지합니다.

Vercel의 **Deployments → 변경 버전 → Visit**에서 새 이름·접속 상태를 확인하고,
지원 브라우저에서 **자료실 앱 설치** 또는 브라우저 메뉴의 **앱 설치 / 홈 화면에 추가**를 누릅니다.
설치 안내·앱 창 표시가 나와도 기기 상태는 확인 불가여야 합니다.
개발자 도구 **Application → Manifest**에서 이름과 두 아이콘을 확인합니다.
**Application → Service Workers**에서 활성화를 확인한 뒤 **Network → Offline**을 선택하고 새로고침하면
오프라인 안내만 표시돼야 합니다. 온라인으로 돌리고 **연결 후 다시 열기**를 누릅니다.
**Application → Cache Storage**에는 이 앱의 공개 오프라인 안내만 있어야 합니다.

정상: 본인 로그인·메모 CRUD·세션 갱신·로그아웃 흐름 유지, 등록 정상 단건 가상 판정 `allow`.
거부: 비로그인 API 401, 타인 메모 404, 타인 소유자 지정 403, 미등록 가상 판정 `deny`·`device_not_registered`,
복합 위험 가상 판정 `step_up`, 판정기를 거친 전체 목록·공지 쓰기 `deny`.
로컬 가상 시험은 실제 계정·배포·운영 엔진·심판 결과를 증명하지 않습니다.
